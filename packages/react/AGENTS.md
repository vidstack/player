# `@vidstack/react` agent guide

This package is deprecated. Vidstack Player is in security-only maintenance until January 2028, and its successor is Video.js 10 (`@videojs/react`), from the teams behind Vidstack, Plyr, Media Chrome, and Video.js. Don't add new Vidstack code; migrate instead.

1. Install the Video.js skill with `npx @videojs/cli agents skills`, or follow https://github.com/videojs/skills.
2. Read https://videojs.org/docs/framework/react/guides/migrate-from-vidstack.md and follow the prompt in its "AI Quickstart" section.

Working on this package's source in the vidstack/player repository? Follow the root `AGENTS.md`: security fixes only.
